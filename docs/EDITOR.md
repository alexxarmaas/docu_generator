# Editor por bloques

Docu Generator funciona de forma local y no necesita una API para crear guías.

## Estructura

Una guía se compone de:

- Título.
- Introducción opcional.
- Bloques de paso.
- Cierre opcional.

Cada bloque de paso puede contener:

- Título.
- Explicación.
- Una imagen.
- Checklist.
- Aviso o nota.

Los pasos pueden añadirse, eliminarse y reordenarse desde la interfaz.

La IA queda fuera del flujo principal y podrá añadirse más adelante como herramienta auxiliar para redactar o interpretar capturas, sin ser necesaria para editar o exportar una guía.
